# সামনের নম্বর প্লেট মেকার (Bangladesh Front Number Plate Maker)

A free web app that makes true-size **front number plates** for motorcycles and scooters, following BRTA's October 2026 public notice that makes front plates mandatory by **15 November 2026**.

## Plate rules it follows

| | Motorcycle | Scooter |
|---|---|---|
| Size | 285 × 50 mm, one line | 200 × 100 mm, two lines |
| Text | Bangla letters and numerals, at least 20 mm high | same |
| Colour | Black text on white | same |
| Extras | No slogans, logos or designs | same |

## Features

- All 64 districts plus metro areas, class letter, series and number; or free text
- English digits converted to Bangla automatically
- Live compliance checklist, including measured character height
- 9 Bangla fonts, border thickness, optional screw-hole guides
- Downloads: true-size PDF, 300 DPI JPG and PNG, A4 print sheet with crop marks
- Responsive on phones, tablets and desktops; light and dark mode

Built with Tailwind CSS, Alpine.js and jsPDF. Single file, no build step: open `index.html` or serve the folder.

> Not affiliated with BRTA. It does not issue official registration plates. Check the official BRTA notice before making a plate.
